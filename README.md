# ロクジョーヒトマ - 操作マニュアル / Controls

本ゲームの基本的な操作方法およびテストプレイ用のデバッグ機能の一覧です。

---

## 🎮 基本操作 (Basic Controls)

| 操作 | PC (キーボード) | スマホ / タブレット (タッチ操作) |
| :--- | :--- | :--- |
| **移動** | 方向キー ( Arrow Keys ) | 画面をタッチして **スライド** |
| **決定 / 攻撃 / 会話** | `Z` キー / `Space` キー | 画面を **短くタップ** |
| **ボム (爆弾)** | `X` キー / `Shift` キー | 画面を **長押し (チャージ発動)** |
| **会話スキップ** | `Enter` キー (長押し) | 画面を **長押し (約1秒)** |
| **マップ開閉** | `M` キー | — (PC専用) |
| **フルスクリーン** | `F` キー | 画面右上 フルスクリーンアイコン |

---

## 🛠 デバッグ操作 (Debug Controls for Testing)

ゲーム起動中、**`Tab` キー** を押すと画面上部にデバッグオーバーレイが表示され、以下のテスト用ショートカットキーが有効になります。

### 1. ステージ・ルーム跳躍
* **`1` キー**: B1F（メインステージ）へジャンプ
* **`3` キー**: B2F（ステージ2）メインへジャンプ
* **`2` キー**: タイトル画面へ戻る
* **`J` キー**: 前の部屋（ルーム）へ戻る
* **`K` キー**: 次の部屋（ルーム）へ進む

### 2. 検証・ショートカットコマンド
* **`C` キー（長押し）**: **壁抜け（No-clip）＆ 移動速度3倍**
* **`L` キー**: 画面内のボス即死・撃破テスト
* **`B` キー**: ボム（爆弾）の即時最大補充
* **`W` キー**: プレイヤー位置に次フロアへのワープホール（`obj_warp_hole`）を召喚
* **`Backspace` キー**: 自爆（HPを0にしてゲームオーバー処理を検証）
* **`R` キー**: ゲームを即時リスタート

### 3. 画面演出・音響トグル
* **`E` キー**: 1-bitモノクロシェーダーのON/OFF
* **`T` キー**: ASMR / Lo-Fi 音響フィルターモードの切り替え
